## 🌟 The Ultimate 7-Point Extractor

[SKILL.md](SKILL.md) defines an advanced agent skill tailored for deep academic paper reading and high-precision technical extraction. It filters out academic noise to deliver structured technical logic and real-world engineering value across 7 key dimensions:

1. **Metadata**: Core details (paper title, authors, venue, type, one-sentence positioning).
2. **The Perfect Abstract**: A high-fidelity summary of problems, methods, and results.
3. **Background & Context**: Fundamental concepts and the overall research landscape.
4. **Problem & Motivation**: Hidden bottlenecks and what motivated this specific work.
5. **Innovation & Methods**: Deep dive into system sub-modules, equations, and structures.
6. **Highlights & Key Takeaways**: Quantitative experiment configurations and detailed tables.
7. **Geek Evaluation**: Brutally honest scores (out of 10) for Innovation, Practicality, and Industry Value.

### 🛠️ Key Capabilities
* **Zero Fluff**: Focuses purely on technical density. No polite introductions or generic wrap-ups.
* **Mathematical & Table Precision**: Formats tables cleanly and converts equations into standard Markdown LaTeX block syntax.
* **Automated Figure Extraction**: Executes Python scripts using `pymupdf` to locate, mask double-column text, crop, and output high-res figures at `3x` scale.
* **HTML Export**: Generates inline-styled HTML ready to be copied and pasted directly into third-party blogging platforms (like WeChat Public Platform, Zhihu, etc.) with original layouts, styles, and equations preserved.

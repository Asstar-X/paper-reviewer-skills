## 📖 项目简介

`project-reader` 是一款专为**微信公众号技术博主、独立开发者与自媒体号主**打造的项目深度拆解与自媒体转译 Agent 技能。

只需向它提供一个网络链接（GitHub 仓库、官方网站、AI 产品页或技术文档），它就会像一位**真切上手折腾过的资深极客博主（“数字生命卡兹克”风格）**，以通俗易懂的大白话、聊天式的亲历叙事，带读者吃透项目的来龙去脉与为什么，基于真实证据提供上手途径，无情指出未明说的局限与暗礁，并直接生成**简约漂亮、全内联 CSS、可直接复制到微信公众号后台的独立 HTML 文件**。

---

## 🎯 核心原则与设计心法

1. **真实与证据第一，严禁凭空臆造（Zero Hallucination）**  
   绝不为了代入感而捏造不存在的运行指令或虚假测试数据。
   - 若原网页有开箱即用的简易命令，原汁原味提取最关键的 1~2 步；
   - 若原网页提供在线 Demo，如实引导读者去体验 Demo；
   - 若原网页无简易命令（需复杂编译或仅为算法权重），**坚决不胡编代码**，实事求是地附上官方项目主页作为兜底。
2. **第一人称真实体验视角（拒绝 AI 腔与八股文）**  
   像朋友聊天一样娓娓道来（“今天想跟大伙聊个特别有意思的事……”）。拒绝出现“底层逻辑、生态闭环、赋能、范式转移”等生造黑话。
3. **兼顾小白与行业从业者**  
   - 小白看：生活常识大白话比喻（“数字滤网”、“擦灰尘 vs 修复老照片”），一看就懂；
   - 行家看：系统架构巧思 + 无情泼冷水（付出的代价、真实暗礁、适用边界）。
4. **移动端呼吸感与极简高保真 HTML**  
   单段原则上不超过 1~3 行，彻底删掉生硬刻板的互动问答，直接输出在手机端阅读极为舒服的 `.html` 文件，全选复制进微信公众平台格式 100% 完美保留。

## 🏗️ 文章标准输出框架

每篇推文严格包含以下流线：

1. **【发文前参考·作者自选标题库】**：提供亲历故事向、痛点好奇向、干货实战向 3 组高点击率标题 + 微信 2.35:1 封面构图与文案建议（位于 HTML 顶层虚线框，发文时可选用）。
2. **【开篇：第一人称真实场景切入】**：以一个真实的日常痛点或探索故事自然拉近与读者的距离。
3. **【一句话说人话】**：大白话核心结论 + 2~3 个最抓人的硬核干货点。
4. **【来龙去脉与为什么】**：以前大家卡在哪 + 作者破局的底层巧思 + 通俗易懂的【补充背景】解释。
5. **【想体验的话，怎么上手？】**：严格基于真实证据，有命令就贴真实命令，无命令就给官方项目地址与 Demo 链接兜底。
6. **【泼冷水：没明说的局限与暗礁】**：付出的代价 + 适用条件与坑（真实客观的工程劝退指南）。
7. **【结尾有温度的收束】**：评价项目价值、适用人群建议与真诚的致谢。

## 🚀 如何使用

在对话中直接发送任何技术项目的链接：

```text
帮我介绍一下这个项目，写成微信公众号文章：
https://github.com/inworld-ai/voice-isolator
```

Agent 会自动提取真实信息，并在当前工作目录直接生成 `[项目名].html`，排版如 [demo-article.html](./demo-article.html) 般简约漂亮，直接复制即可推送！
